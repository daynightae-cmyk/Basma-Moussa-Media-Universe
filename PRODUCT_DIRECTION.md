## Brand and photos
- Keep the established navy / champagne-gold visual identity, brand logo, typography, cinematic golden thread, and existing meaningful animation.

## Next product experience
1. A dramatic but elegant splash: one golden thread draws a theatrical mask and a balanced justice-scales motif, before revealing only the original logo. Then a prominent bilingual Enter Basma's Universe / ادخل عالم بسمة button. Provide skip, reduced-motion, touch support and a safe non-animated fallback.
2. Cinematic homepage scene transitions and carefully paced scrolling without layout instability, fake loading, confusing navigation, or excessive animation.
3. A separate, believable interactive director studio. Real 3D or high-quality 2.5D seated furniture: independent chairs and table placement, verified camera presets, lighting temperatures, accessories, real drag/rotate controls and clear state persistence. Preserve the existing studio scenes.
4. ON AIR is a stateful broadcast indicator, never merely decorative success. Display ON AIR only when a real connected live transport and authorized session exist. Until then: Studio Preview / معاينة الاستوديو, with visible simulation disclosure. For actual streaming, require backend connection, permissions, media device consent, reconnect lifecycle, room roles, bounded tokens, and recording consent where applicable.
5. AI features must be grounded, bounded for credits and permissions, and must never invent published episodes or confidential material. All form submissions require real delivery paths and feedback.

## Nonnegotiable quality gates
- Preserve all existing content and distinctive work in this repo.
- Do not blindly import a page or rewrite from the old Next.js repository.
- Compare against current working UI before replacing layouts or animations.
- Arabic RTL and English LTR, desktop and mobile, focus/keyboard access, reduced motion, image alt text and navigation.
- Run npm test, npm run lint and npm run build. Review GitHub Actions after pushing and do not call production ready based on compilation alone.
- Do not deploy or connect to Base44 automatically; project linking and deployment need review.

## Proof of delivery
Every future change should include exact files changed, Git SHA, tests and outputs, screenshots of desktop and phone states, runtime behavioral evidence, actual LIVE transport state if relevant, and deployment state separately.
